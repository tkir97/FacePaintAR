# AR Face Painter — Polished Studio UI

This build keeps the existing camera, worker tracking, canonical face model, paint logic,
pinch zoom, templates, stamps and emoji behavior, while redesigning the Mask Studio UI.

## UI improvements

- Professional grouped control sections
- Clear primary drawing toolbar
- Visible active tool state
- Cleaner Paint / Stickers / Templates / View & AR hierarchy
- Better spacing and typography
- More consistent button and field styling
- Clear destructive styling for Clear Mask
- Cleaner mobile layout
- Sticky mobile drawing toolbar
- Live colour hex display
- Version-heavy placeholder copy removed
